    How this works

    CrunchLabs sells a Build Box subscription for $29.95 a month. Each month they hide one Platinum Ticket in a single random box somewhere in the world. If you find it, you win a trip to visit Mark Rober!

    Roughly 200,000 boxes ship each month, so any one box you open has about a 1 in 200,000 chance of hiding the ticket.
